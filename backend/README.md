# بک‌اند آزمایشی دانلودینو

این API فقط لینکِ عمومیِ یک پست یا ریل اینستاگرام را می‌پذیرد؛ لینک پروفایل، محتوای خصوصی و دانلود انبوه پذیرفته نمی‌شود. فقط محتوایی را دریافت کنید که مالک آن هستید یا اجازهٔ دریافتش را دارید. فایل‌ها موقت‌اند و روی دیسک دائمی نگه‌داری نمی‌شوند. به‌دلیل تغییرات اینستاگرام، استخراج ممکن است گاهی در دسترس نباشد.

## اجرای محلی

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python app.py
```

برای تبدیل صدا، `ffmpeg` باید در سیستم نصب باشد.

## استقرار Docker/Render

Dockerfile در همین پوشه قرار دارد و FFmpeg را نصب می‌کند. از ریشهٔ مخزن، build context برابر `.` و Dockerfile برابر `backend/Dockerfile` باشد. متغیر محیطی `ALLOWED_ORIGIN` باید `https://amirrezakiyani.github.io` باشد.

طرح رایگان Render ممکن است بعد از بی‌کاری سرویس را متوقف کند؛ اولین درخواست پس از بیدارشدن می‌تواند کند باشد. این نسخه برای آزمایش است، نه تضمین دسترس‌پذیری دائمی.

## API

`POST /api/download` با بدنهٔ JSON:

```json
{"url":"https://www.instagram.com/reel/.../","kind":"video"}
```

مقادیر `kind`: `video`, `photo`, `audio`. مسیر `GET /health` وضعیت سرویس را گزارش می‌کند. API حداکثر ۵ درخواست از هر IP در دقیقه و فایل حداکثر ۱۰۰ مگابایت می‌پذیرد.
