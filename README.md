# دانلودینو

دانلودینو یک ابزار وب برای دریافت محتوای عمومی و مجاز اینستاگرام است. رابط کاربری روی GitHub Pages و API آزمایشی روی یک سرویس موقت اجرا می‌شود.

## استفاده

1. لینک عمومی پست، ریلز یا ویدئوی اینستاگرام را وارد کنید.
2. نوع خروجی را انتخاب کنید: ویدیو، عکس یا موسیقی/MP3.
3. روی «دریافت فایل» بزنید.

## API آزمایشی

آدرس فعلی API:

```text
https://8000-iv54n61zzo2l7jayeit3w-23209c66.us4.manus.computer
```

این آدرس برای تست رایگان است و دائمی یا تضمین‌شده نیست؛ اگر محیط آزمایشی متوقف یا hibernate شود، دانلود هم موقتاً از کار می‌افتد.

قرارداد API:

```http
POST /api/download
Content-Type: application/json

{"url":"https://www.instagram.com/reel/.../","kind":"video"}
```

مقادیر `kind`: `video`, `photo`, `audio`.

## محدودیت و مسئولیت

این نسخه با `yt-dlp` و `ffmpeg` محتوای عمومی را به‌صورت آزمایشی استخراج می‌کند. تغییرات اینستاگرام، rate limit یا نیاز به ورود می‌تواند باعث شکست درخواست شود. حساب خصوصی پشتیبانی نمی‌شود. فایل‌ها در دیسک دائمی ذخیره نمی‌شوند و برای جلوگیری از سوءاستفاده، محدودیت درخواست فعال است.

از این ابزار فقط برای محتوایی استفاده کنید که مالک آن هستید یا اجازهٔ دریافت و استفاده از آن را دارید. این پروژه وابسته یا تأییدشده توسط Instagram یا Meta نیست.

## اجرای محلی

```bash
cd backend
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python app.py
```

برای اجرای دائمی باید بک‌اند روی یک سرویس میزبانی پایدار مستقر شود؛ GitHub Pages به‌تنهایی امکان اجرای `yt-dlp` یا `ffmpeg` را ندارد.
