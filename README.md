# دانلودینو

نسخهٔ استاتیک ابزار بررسی لینک اینستاگرام برای GitHub Pages.

## نکتهٔ مهم دربارهٔ دانلود واقعی

GitHub Pages فقط فایل‌های استاتیک را سرو می‌کند. مرورگر به‌تنهایی نمی‌تواند از روی لینک پست یا ریلز اینستاگرام، فایل رسانه‌ای را استخراج کند؛ این کار به یک بک‌اند مجاز، کنترل خطا، CORS و رعایت شرایط استفاده و حقوق صاحب محتوا نیاز دارد. بنابراین این پروژه دیگر دکمهٔ جعلی ندارد:

- آدرس مستقیم فایل‌های مجاز (`.mp4`, `.mp3`, `.jpg`, `.png`, ...) را در مرورگر دریافت می‌کند.
- لینک اینستاگرام را اعتبارسنجی و دسته‌بندی می‌کند.
- در صورت تنظیم `window.DOWNLOAD_API_URL`، درخواست را به بک‌اند شما می‌فرستد.
- رمز عبور اینستاگرام را درخواست نمی‌کند.

## قرارداد API اختیاری

صفحه یک درخواست `POST` با بدنهٔ زیر ارسال می‌کند:

```json
{"url":"https://www.instagram.com/reel/.../"}
```

پاسخ موفق باید حداقل این فیلد را داشته باشد:

```json
{"downloadUrl":"https://cdn.example.com/media.mp4","filename":"media.mp4","mimeType":"video/mp4"}
```

در `index.html` مقدار زیر را با آدرس API خودتان جایگزین کنید:

```js
const DOWNLOAD_API_URL = 'https://api.example.com/instagram/download';
```

API باید فقط محتوایی را پردازش کند که کاربر مالک آن است یا اجازهٔ دریافتش را دارد؛ از دورزدن ورود، محتوای خصوصی یا محدودیت‌های اینستاگرام استفاده نکنید.

## انتشار

فایل‌های `index.html` و `README.md` را روی شاخهٔ فعال GitHub Pages قرار دهید. برای دانلود واقعی لینک اینستاگرام، API را جداگانه روی یک سرویس بک‌اند یا serverless مستقر کنید و CORS دامنهٔ GitHub Pages را فعال کنید.
